# 从 0.0.2 到现在

除了文末留下的两项，没有新的残留问题。下面按版本说你会碰到的变化。0.0.10 已经进仓库，还没发到 npm。

**0.0.2** 只把商店里的介绍写短了。npm 上那个包比现在这套旧。

这个号后面有一段没有升版本：聊天改成整屏输入，正在回答或跑命令时可以打断，也有了 `/cost` 和 `/provider`。配置写在家里的 `~/.ti/settings.json`。

**0.0.3** 聊过的话会记在当前项目里，关掉再开还能接着，也可以挑一份旧的继续。两个 ti 不会同时写同一份记录。写到一半断掉，不会把整份记录弄坏。

**0.0.4** 对话太长可以 `/compact`，自己也会收成一段摘要再往下聊。接口说装不下时，先收一下再重试你刚说的那句。没标窗口大小的模型不会自动收。

**0.0.5** 打开旧对话后，上箭头能翻到你以前亲手打的话。一行末尾打 `\` 再回车，可以接着写下一行。摘要和被你打断的回复单独记着，恢复时不会当成你打的那句。

**0.0.6** 放了技能之后，打 `/名字` 就能用，`/skills` 看有哪些。斜杠命令后面带的参数，回车不会弄丢。不会再自动改你项目的 `.gitignore`。

**0.0.7** 这版主要是把测试补齐。打断或超时会把命令拉起来的子进程一起停掉。有的接口换行方式和常见的不一样，以前会把回复读丢，现在认了。

**0.0.8** 可以看版本号。说明有英文和中文。打包前会自己检查一遍产物。

**0.0.9** `ti update` 把已经装上的命令更新到官方源上的新版本。能认出是用哪家装的。位置不对或目录不能写，就只告诉你该敲什么，不会硬装。用源码直接跑的时候不更新。

**0.0.10** 更新能顺着正在跑的文件找到安装位置，快捷方式也对得上。压缩如果会把记录撑过大约 32MB 就直接拒绝，写到一半失败会把文件缩回原来那么长。某句话没存上时，撤回不会把上一句已经存好的删掉。会等你敲键盘的命令不再一直卡住。写文件没给正文就失败，空内容仍可以写，用来清空文件。回答显示到一半、接口自己断了，已经出来的字会留下，你那句也不撤；你自己按打断，还是原来那样。设置文件读坏或解析不了时，这次不会拿空的盖掉原来的文件。

留下没修的两项：命令输出特别大时，还是先全部收进内存再截短；读大文件时，还是先整份读进来再按行截。
